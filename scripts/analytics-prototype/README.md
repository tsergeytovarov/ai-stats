# Analytics prototype

Эталонная референс-реализация методики вкладки «Аналитика» (спека
`docs/spp/04-specs/2026-07-11-burn-next-design.md`). Python 3.12+, без зависимостей.

- `experiment2.py` — парсеры транскриптов Claude Code (`~/.claude/projects`) и Codex
  (`~/.codex/sessions`), лестницы моделей, эвристика ступеней, выгрузка судейской
  выборки. Окно — 7 дней.
- `judge_load.py` — загрузка вердиктов LLM-судьи (разметка n=79 от 2026-07-11)
  и расчёт судейских коэффициентов по стратам.
- `experiment3.py` — продовая карточка за 30 дней: суммы, лимиты Codex (эпохи
  rate_limits), утечки с советами, шпаргалка моделей. Импортирует парсеры из
  `experiment2.py`.

Запуск: `python3 experiment3.py` (из этого каталога). Используется как контрольный
прогон для критерия приёмки №3 спеки: реализация в приложении должна сходиться
с прототипом на тех же данных с точностью ±5%.

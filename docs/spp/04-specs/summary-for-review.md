# Что делает следующая версия Burn — на аппрув

Коротко: Burn перестаёт быть «статистикой всего» и становится инструментом про
AI-расходы. Убираем GitHub и друзей, добавляем вкладку «Аналитика», которая
советует, где ты переплачиваешь на дорогих моделях.

## Две вкладки вместо трёх категорий

Внизу попапа остаётся переключатель на **две** вкладки:

- **Расходы** — ровно то, что сейчас на AI-вкладке: сумма, дельта, топ моделей,
  разбивка по источникам, спарклайн. Периоды День / Неделя / Месяц как были.
- **Аналитика** — новая. Всегда за последние 30 дней, без переключателя периода.

## Что показывает «Аналитика»

Карточка сверху вниз:

1. **За последние 30 дней** + диапазон дат.
2. **По каждому агенту** (Codex, Claude Code): сколько потрачено токенов и денег;
   для Codex — сколько недельного лимита в среднем съедаешь; строка
   «Утекает ≈9% = $168/мес ≈ 5.9 п.п. недельного лимита».
3. **Главные утечки и что делать** — топ-3 повторяющихся паттерна с ценником и
   советом. Например: «412 фоновых уведомлений ушло на opus ≈ $92/мес → обрабатывай
   дешёвой моделью»; «роль Voice Match в трубе рерайта крутится на opus ≈ $18/мес →
   зафиксируй sonnet в конфиге».
4. **Шпаргалка: какую модель когда** — для Codex описания берутся живьём из самого
   Codex, для Claude — короткая таблица (haiku — поиск, sonnet — основная работа,
   opus — архитектура/дебаг, fable — самое тяжёлое).

Данных пока нет → «Пока нечего анализировать, поработай с агентами несколько дней».
Утечек нет → «Утечек не видно: модели подобраны по задачам».

## Виджеты

- **Small / Medium** — как сейчас, только исчезает упоминание коммитов.
- **Large** — становится витриной советника: слева расходы, справа топ моделей,
  снизу строка «Утекает ≈$X/мес · <главная утечка>».

## Что уходит

- Вкладка **GitHub** и вся статистика коммитов/строк.
- Вкладка **Друзья** и лидерборд — целиком, вместе с friend-кодом в настройках.
- В настройках остаются **Общие**, **Аккаунт** (вход) и экспорт/импорт базы.

## Что остаётся

- **Авторизация через GitHub** — она нужна, чтобы синхронизировать твою статистику
  между устройствами. Вход и синк работают как раньше, просто без витрины друзей.
- Актуальные цены на все живые модели (gpt-5.6-sol/terra/luna, spark и др.) — чтобы
  виджет показывал реальную стоимость, а не ноль на новых моделях.

## Важная честная оговорка

«Мог быть дешевле» — это оценка по форме задачи (короткий вопрос без правок кода на
дорогой модели), а не гарантия, что дешёвая справилась бы. Экономия считается как
«те же токены по ставке модели попроще». Числа приблизительные, порядок — надёжный.
